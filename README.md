# Socio-Emotional Skills Questionnaire Website

This is a static, Google-search-friendly documentation website for the socio-emotional skills questionnaire used in the study:

**Socio-Emotional Skills and Mathematics Performance of BSEd Mathematics Students**

## Files
- `index.html` — main webpage
- `styles.css` — styling
- `script.js` — small accessibility/navigation enhancement

## Publishing
Upload all three files to a public static host such as GitHub Pages. After publication, use Google Search Console to verify the site and request indexing.

## Important provenance note
The site documents the questionnaire and its stated theoretical basis. It does not claim that the website was the historical/original source of the questionnaire.

Before publication, replace the placeholder canonical URL in `index.html` (`https://example.com/`) with the actual public URL of the website.
